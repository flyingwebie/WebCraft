# PROTOTYPE: key admin screens (throwaway, never merged)

Answers [What do the key admin screens look like? (Pen design)](https://github.com/flyingwebie/WebCraft/issues/22).

Open `admin-screens.prototype.pen` in Pen, or look at `png/`. Every screen uses the variant A navigation (one sidebar with a context switcher) chosen in [How is the admin organised? (Pen design of navigation)](https://github.com/flyingwebie/WebCraft/issues/20).

The shadcn preset `b1Fk3bmIS` is applied: zinc base colours, an orange primary, Inter, lucide icons and medium radius. The colours were set by hand from the preset's theme, not generated by the shadcn CLI.

## Rebuilding

`src/` holds the scripts that drew the file through the Pen CLI in headless mode. Paths in them point at `/tmp/penproto`:

```sh
node src/run.mjs screens.pen src/vars.js src/gen/*.js
```
