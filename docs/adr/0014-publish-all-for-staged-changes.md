# Publish all sits alongside per-item publishing in v1

Every Draft is still published on its own, but v1 also has **Publish all**: one action that publishes every Draft of a Site the person may publish (Entries, Globals, Templates, Components, Forms, the Design system), after showing the list and letting them untick items. This reverses the earlier choice to leave whole-Site releases until after v1. Agencies show clients upcoming work on the Site's Staging address, and a redesign that touches a Template and several Pages must go live together, not piece by piece.

## Considered Options

- **Per-item publishing only**: rejected because a change spread over several items would reach visitors half-done while it was published one item at a time.
- **Named releases (a saved set of Drafts, scheduled or published together)**: rejected for v1 as more to build than Publish all, which covers the staging use. It may come with the editorial workflow.
- **A separate staging copy of each Site, pushed over the live one**: rejected because copying a Site would overwrite Content clients changed in the meantime.
